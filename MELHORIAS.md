# Modernização do projeto

## Arquivos principais atualizados

- `index.html`
- `linhadotempo.html`
- `conquistas.html`
- `galeria.html`
- `guanabara.html`
- `css/style.css`
- `script.js`
- `README.md`

## Novos recursos

- Navbar sticky no desktop e drawer acessível no mobile.
- Página atual destacada com `aria-current`.
- Hero responsivo na Home.
- Atalhos para Linha do Tempo, Conquistas e Galeria.
- Formulário funcional com Formspree.
- Timeline com `IntersectionObserver`.
- Conquistas, progressões e especialidades convertidas de tabelas para cards responsivos.
- Galeria em CSS Grid, lazy loading e lightbox com teclado, Escape, anterior/próxima e swipe.
- Página Mestre modernizada com vídeo 16:9 responsivo.
- Footer unificado e botão de voltar ao topo.
- Estados de foco, navegação por teclado e suporte a `prefers-reduced-motion`.
- Bootstrap removido; o site usa apenas HTML, CSS e JavaScript.
